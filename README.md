# 🚀 AstroVerse — Space Exploration Website

Explore the wonders of our solar system with AstroVerse, an interactive
space exploration website designed to make learning about planets
more engaging and enjoyable.

AstroVerse presents planet information through an attractive space-themed
interface, interactive planet cards, search functionality, and interesting
space facts.

## 🌌 Features

- 🪐 Interactive Planet Cards
- 🔍 Search planets by name or type
- ↕️ Sort planets by name, diameter, or distance
- 📚 View detailed information about planets
- 🌠 Discover random space facts
- 🎨 Modern, space-themed user interface
- 📱 Responsive design for different screen sizes
- 📂 Dynamic planet data loaded from a JSON file

## 🛠️ Technologies Used

- HTML5 — Website structure
- CSS3 — Styling, animations, and responsive layout
- JavaScript — Interactivity and dynamic content
- JSON — Planet information and data storage

## ⚙️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Open `index.html`.
5. Right-click inside the editor.
6. Select **Open with Live Server**.
7. Explore the AstroVerse website in your browser.

Note: Run the project through a local web server because JavaScript
uses `fetch()` to load data from `planets.json`.
